##  Installation

Clone the repository

```bash
git clone https://github.com/ZyadTaha-hub/zth-shop.git
```

Go to the project folder

```bash
cd zth-shop
```

Install dependencies

```bash
npm install
```

Run the project

```bash
npm run dev
```
